# Утро

Личный новостной дайджест: GitHub Actions собирает новости и вызывает выбранного провайдера, Git хранит историю, GitHub Pages показывает архив. Своего сервера, платной базы и сторонних Python-зависимостей нет.

## Что уже есть

- Пять групп: AI-агенты (подробно), глобальные технологии, иммиграция в UK, главное о России, переговоры об урегулировании войны.
- 17 источников: официальные релизы Codex, Claude Code, Gemini CLI, Agents SDK и LangGraph; OpenAI, Anthropic, Cursor, Google AI, Simon Willison, HN, The Verge, Ars Technica, GOV.UK, BBC Russian, Meduza и Guardian Ukraine.
- История выпусков, поиск, фильтры, отдельные страницы, Markdown и JSON Feed. Закладки и прочитанное — только в текущем браузере.
- Отправка короткого сообщения в Telegram со ссылкой на полный выпуск.
- Один JSON-контракт для всех моделей. Ссылки подставляет программа из источников; неизвестные или повторные ссылки блокируют публикацию.

**Архив и репозиторий публичны.** Не добавляйте приватные источники, личные документы или секреты в конфигурацию. Ключи находятся только в Actions Secrets. На сайте нет входа и редактирования серверных настроек.

## Подключить модель

По умолчанию выбран `claude-cli`, на котором проверен первый выпуск. Для автоматического запуска добавьте его секрет.

В `config/settings.json` измените `provider` и при необходимости `model`. Альтернатива — Repository Variables `DIGEST_PROVIDER` и `DIGEST_MODEL`: они переопределяют файл без изменения кода. Названия моделей выбираются независимо от адаптера.

| provider | Доступ | GitHub Secret | model |
|---|---|---|---|
| `links` | Без модели: выдержки и ссылки | Не нужен | Пусто |
| `gemini` | Google Gemini API | `GEMINI_API_KEY` | По умолчанию `gemini-3.8-flash` |
| `claude-cli` | Claude Code, включая подписку | `CLAUDE_CODE_OAUTH_TOKEN` **или** `ANTHROPIC_API_KEY` | По умолчанию `haiku` |
| `codex` | Официальный Codex Action в GitHub | `OPENAI_API_KEY` | Пусто = выбор Codex; можно указать явно |
| `anthropic` | Claude Messages API | `ANTHROPIC_API_KEY` | Укажите доступную API-модель |
| `openai` | OpenAI Responses API | `OPENAI_API_KEY` | Укажите доступную API-модель |

Для Claude с подпиской создайте токен командой `claude setup-token` и сохраните результат в GitHub Secret `CLAUDE_CODE_OAUTH_TOKEN`. Не отправляйте токен в чат и не коммитьте его. Для `claude-cli` с подпиской не задавайте одновременно API-ключ, чтобы случайно не выбрать API-биллинг.

Codex в GitHub подключён через `openai/codex-action`, с API-прокси, read-only sandbox и отключёнными инструментами выполнения команд. Перенос `auth.json` личной подписки в публичный репозиторий не поддерживается этим проектом. Локальный адаптер `codex exec` может использовать уже существующую авторизацию CLI.

`links` — явный режим проверки сбора, без перевода и тематического AI-отбора. Перехода на другую или платную модель при ошибке **нет**. Бесплатность Gemini зависит от доступности выбранной модели и лимитов вашего аккаунта; этот код не включает платный биллинг.

После настройки запустите **Actions → Digest and Pages → Run workflow**. Чтобы получить новый выпуск в тот же день после смены провайдера, отметьте **Create an additional edition today**.

## Подключить Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) затем откройте созданного бота в Telegram и нажмите **Start**.
2. Добавьте Secrets `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в [настройках репозитория](https://github.com/mike0sv/news-digest/settings/secrets/actions). Chat ID можно получить из `getUpdates` вашего бота; не публикуйте URL с токеном.
3. `telegram.enabled` уже включён. При отсутствии секретов workflow оставляет notice и ничего не отправляет. Выпуски в режиме `links` по умолчанию в Telegram не уходят.
4. Запустите workflow. Последний настоящий AI-выпуск за текущий день будет доставлен после публикации сайта.

История сохраняется **до** отправки. После подтверждения Telegram записывается receipt, поэтому обычный повтор workflow не дублирует сообщение. Перед новой отправкой сохраняется `delivery_uncertain`: если ответ потерян или произошёл таймаут, дальнейшая автоматическая отправка останавливается. Проверьте чат: если сообщение есть, запишите его `message_id` в receipt, чтобы повтор обновил исходное сообщение; если сообщения нет, снимите флаг и повторите запуск. При жёсткой остановке runner до сохранения receipt в Git повтор всё же возможен. Не включайте параллельную ручную отправку.

## Источники, отбор и расписание

Источники, группы, приоритеты и ограничения — в одном `config/settings.json`. Сменить модель можно, не трогая сбор, хранение или интерфейс. Добавить адаптер — реализовать `Result(data, usage)` в `digest/providers.py` и зарегистрировать имя.

Основной вход — RSS/Atom. Anthropic News и Cursor читаются с их публичных страниц; их разметка может измениться. Для UK дополнительно читается GOV.UK Content API с недавними изменениями документа. Общие страницы разделов исключены. Недоступный источник отмечается; если недоступны все, выпуск не создаётся.

Общие мировые события поступают из [BBC World RSS](https://feeds.bbci.co.uk/news/world/rss.xml)
в группу «Мир: главное». Порог включения высокий: крупные решения, кризисы и результаты
международных переговоров; пустая группа допустима. Важные этапы космических миссий
допускаются в «Технологиях». После калибровки на подборке «Контекста» отдельные выходы
из МУС, региональные сюжеты об Армении и ранние обсуждения ограничений игр/уголовных
наказаний пропускаются. Предложения существенных визовых ограничений и санкций
могут войти коротко, с явным указанием стадии. AI-компании и переговоры об Украине
сохраняют свои тематические группы независимо от источника.

По умолчанию рассматриваются последние 48 часов. После ошибки структуры или ссылок допускается одна попытка исправления тем же провайдером; затем запуск останавливается. Тексты из RSS могут быть неполными. В зависимости от объёма источников новые публикации могут не попасть в ограниченный набор кандидатов. Для GOV.UK изменение даты обновления создаёт новую версию того же URL. Удаляются повторы URL/версий и точных заголовков; смысловые повторы объединяет модель. Предыдущие сюжеты за 14 дней передаются ей для сравнения. Это мониторинг выбранных источников, а не гарантия охвата всего интернета.

Ежедневный запуск — в 00:49 `Europe/London`, с запасом до утра на задержки GitHub. `morning_hour: 0` разрешает ночную обработку; выпуск получает дату дня запуска и использует обычное окно последних 48 часов без уже опубликованных новостей. Таймзона задана прямо в расписании GitHub и учитывает летнее время. Существующий выпуск не генерируется повторно; подтверждённая доставка не повторяется, незавершённая публикация или доставка восстанавливается. При смене часа/таймзоны исправьте и настройки, и расписание workflow. [GitHub может задерживать или пропускать расписание](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule), поэтому точное время и ежедневный запуск всё ещё не гарантированы.

В Git коммитятся только метаданные статей, готовые выпуски и квитанции доставки. Исходный текст и prompt хранятся в игнорируемом `.runtime/` только во время выполнения. Pages публикует только собранную папку `site/`.

## Локальная проверка

Нужен Python 3.11+; на GitHub используется 3.12. Для проверки JavaScript — Node; для CLI-провайдеров — соответствующий CLI.

```sh
python -m unittest discover -s tests -v
python -m digest check
python -m digest run
python -m digest build
python -m http.server --directory site 8000
```

Команды также доступны отдельно: `prepare`, `generate`, `build`, `deliver`. Обычный `run` повторно не создаёт выпуск того же дня; `run --force` создаёт дополнительный. Telegram отправляется только отдельной командой `deliver`.

### Важность, тренды и развитие историй

Не более трёх важных сюжетов в выпуске; ноль — нормальный результат. В Telegram они
помечены 🔥, на сайте выделены цветом и доступны через фильтр «Только важное».
Причину важности можно увидеть у метки. Проходные новости сохраняют полезные сигналы
о проектах, обсуждениях и ограничениях агентской разработки.

Hacker News даёт общие топ-истории, AI coding, agent и Show HN AI. GitHub даёт снимки
активных популярных AI-проектов; после второго замера доступны изменения звёзд.
Популярность не считается доказательством качества или новой функциональности.
Связь «Ранее» ведёт к конкретной карточке предыдущего выпуска и проверяется приложением.

### Ручной запуск с датой

В Actions → Digest and Pages → Run workflow задайте `date: YYYY-MM-DD` либо оставьте
пустым для обычного выпуска. `force` разрешает дополнительную редакцию.

```sh
python3 -m digest run --date 2026-11-20
```

Дата ограничивает публикации календарным днём в `timezone`. Будущие даты отклоняются.
Ретроспектива использует сохранившиеся датированные ленты, историю GitHub Releases и HN;
это неполное восстановление, а не копия утреннего выпуска. Текущие GitHub-звёзды и
недатированные страницы исключаются. HN-баллы наблюдаются сейчас. Прошлые выпуски
не рассылаются в Telegram и не откатывают текущее состояние. Для недельного прогона
запускайте дни последовательно от ранних к поздним: так доступны связи с прошлым.

### Telegram Instant View

Полный выпуск дополнительно публикуется в Telegraph. Telegram поддерживает Instant View
для этих страниц: в сообщении есть ссылка «Читать полный выпуск · Instant View» и предпросмотр.
GitHub Pages остаётся архивом с фильтрами. Повторная публикация обновляет ту же страницу.

Создайте аккаунт через [Telegraph API](https://telegra.ph/api#createAccount) и добавьте
его `access_token` как секрет `TELEGRAPH_ACCESS_TOKEN`. Не публикуйте `auth_url` или токен.
Настройка: `telegram.instant_view: true`. Публикация выполняется перед сборкой архива;
ошибка публикации не должна приводить к сообщению с несуществующим полным выпуском.

Инструкции для дальнейшей разработки — в [AGENTS.md](AGENTS.md).

В GitHub Actions источник Releases использует встроенный `GITHUB_TOKEN` для узкого
GraphQL-запроса без многомегабайтных списков бинарных файлов. Локально этот токен можно
передать через окружение; без него используется ограниченная REST-история. Для новых
источников можно задать `candidate_limit`, чтобы снимки популярных репозиториев не
вытесняли свежие релизы из окна отбора.

При правке уже отправленного сегодняшнего выпуска бот редактирует своё исходное
сообщение; повторный запуск с тем же текстом ничего не отправляет.

### Получатель Telegram

`TELEGRAM_CHAT_ID` задаёт единственного получателя. Для публичного канала используйте `@username` и добавьте бота администратором с правом публикации. При смене получателя текущий выпуск отправляется в новый чат один раз; прежние сообщения не редактируются. Отметки доставки разделены по хешу получателя. Старые отметки без получателя сохранены как история и не блокируют первую доставку после миграции.
